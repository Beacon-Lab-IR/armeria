# CIS-CAT Pro
CIS-CAT Pro (Center for Internet Security — Configuration Assessment Tool Pro) es la herramienta oficial de evaluación de configuración de CIS (Center for Internet Security). Permite escanear sistemas operativos, aplicaciones y dispositivos de red contra los CIS Benchmarks (guías de configuración segura consensuadas por la comunidad) y reportar el grado de cumplimiento ("compliance") de cada equipo auditado.

## Qué hace
* Evalúa el sistema contra las recomendaciones de un CIS Benchmark específico (p. ej. Windows 10, Windows Server 2019, Ubuntu Linux 22.04, Cisco IOS, etc.).
* Genera un reporte de cumplimiento indicando qué controles pasan, cuáles fallan y cuáles no son aplicables.
* Produce resultados en formatos legibles por máquina (HTML, CSV, XML, JSON) para integrarlos con SIEM, GRC o herramientas de ticketing.
* Soporta autenticación local y remota (credenciales, SSH, WinRM) para auditar múltiples endpoints desde una consola central.
* Permite crear perfiles personalizados (custom profiles) para endurecer o relajar reglas según la política de la organización.
##  Ediciones
* CIS-CAT Pro Assessor — escanea y reporta.
* CIS-CAT Pro Dashboard — consolida resultados de múltiples Assessors en una vista central con histórico y tendencias.
## Cuándo usarlo
Hardening de sistemas, auditorías de cumplimiento (PCI-DSS, HIPAA, NIST, etc.), revisión periódica de configuración de endpoints y servidores, y evidencia para procesos de certificación.
